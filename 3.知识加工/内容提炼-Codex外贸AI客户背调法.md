## 三、核心方法论重构：AI 外贸客户背调五步法

> 以下内容 `[补充资料]`：综合宁波商务局 AI 背调培训课程、网易外贸通实操指南、Daniel 外贸 AI 的 Claude 背调法、孚盟 AI 智能体方案等多篇公开资料，按"5步法"框架重构，用于补全原文标题所承诺的方法论全貌。**非原文逐字内容，但与原文主题高度相关。**

### 第一步：归集基础线索，统一建档

**目标**：在背调前完成客户基础信息结构化录入，明确背调方向。

**操作要点**：
- 录入客户企业名称、所属国家、主营产品、HS 编码、联系人等基础资料
- 明确背调方向：新客真伪核验 / 潜客分层筛选 / 重点客户深度调研 / 大额订单风险排查
- 将展会询盘、社媒私信、自主开发、广告流量、老客转介绍等全渠道线索统一归档
- 利用 AI 自动完成线索去重、补齐企业基础信息、生成独立客户档案

**Codex 类 AI 的作用**：替代手动制作 Excel 表格，用自然语言指令完成建档与字段补齐，适合个人 SOHO 与小团队批量管理。

### 第二步：AI 资质核验，过滤无效客户

**目标**：依托合规数据库核验企业真实性，剔除空壳公司与无效询价主体。

**核验维度**：
- 企业经营状态、注册年限、人员规模
- 官方渠道与联系方式有效性（邮箱后缀是否匹配官网域名）
- 域名注册时间（Whois 查询，<6 个月高风险）
- Google Maps 街景核实注册地址（避开居民区/虚拟办公室）
- LinkedIn 员工数量（<10 人决策链短但量小；>500 人需定位具体部门）

**关键判断**：
- 正规采购方通常使用企业官网邮箱后缀，Gmail 等个人邮箱多为 SOHO 或采购代理
- 官网使用免费模板、域名注册于当月、地址为虚拟办公室 → 高风险信号

### 第三步：拆解贸易数据，分析采购能力

**目标**：调取历史进出口数据，研判客户采购实力与产品匹配度。

**核心分析内容**：
- 历史采购品类、价格区间、采购频次、单次下单体量
- 淡旺季规律、合作货源国家
- 近三年采购体量与核心品类变化趋势（扩张 / 收缩 / 转型）
- 采购量骤降、供应商频繁更替、新增 HS 编码 → 供应链调整信号，识别切入窗口
- 客户类型分层：中间商 / 批发商 / 终端工厂

**数据来源**：
- 海关提单数据（全球 230+ 国家及地区进出口记录）
- ImportGenius / Panjiva 等海关数据平台
- 网易外贸通、孚盟等外贸专属 SaaS

**实战案例** `[补充资料]`：某家电公司跟巴西客户打交道，用系统查出客户两年买了八次空调，对接的是采购总监，无纠纷记录，一天完成背调，比传统方式快五天。

### 第四步：穿透供应链 + 决策链，锁定对接方案

**目标**：解决"不知道找谁、不知道如何切入"两大难题。

**供应链穿透**：
- AI 自动罗列客户长期合作的海外供应商
- 分析其供货周期、产品短板、价格接受度
- 给出差异化开发建议（如：发现现有供应商主打低价 → 我方聚焦"智能调光技术 + 5 年质保"替换）

**决策人挖掘**：
- 依托公开合规数据，挖掘企业股东、采购负责人、运营高管
- 匹配合规联系方式（已验证邮箱、领英链接、WhatsApp）
- 标注岗位权限，降低对接基层无决策权人员的概率
- LinkedIn 筛选职位含 Purchasing、Sourcing 的员工

**实战案例** `[补充资料]`：某 LED 厂商通过 AI 发现西班牙客户现有中国供应商主打低价策略，遂聚焦"智能调光技术 + 5 年质保"，成功替换原有供应商。

### 第五步：风险预警 + 报告生成，制定跟进策略

**目标**：完成风险筛查，输出可视化背调报告，制定差异化跟进方案。

**风险排查**：
- Google 搜索"公司名 + scam"、"公司名 + complaint"
- 负责人姓名 + fraud 组合检索
- 检索海外舆情与工商信息，大额订单调取中信保信用报告
- 实时监测客户所在国政策变动（关税调整）、行业负面新闻

**客户分级管理**：

| 等级 | 特征 | 策略 |
|------|------|------|
| A级（重点投入） | 官网规范、持续进口记录、采购经理级联系人、规模>50人 | 定制化开发信、5日内高频跟进、样品优先安排 |
| B级（常规维护） | 官网信息不全、无公开海关数据、职位模糊 | 标准化邮件+14日周期跟进、引导提供补充信息 |
| C级（谨慎接触） | 个人邮箱/Gmail、无正规官网、LinkedIn无企业信息 | 基础模板邮件后暂停，待客户主动联系 |

**报告输出**：5 分钟生成包含"采购习惯分析 - 竞品对比 - 沟通策略建议"的可视化报告，支持一键导出 PDF 或同步至 CRM。

## 四、万能 Prompt 模板（基于 Claude/Codex 类 AI）

> `[补充资料]` 以下 Prompt 模板来自 Daniel 外贸 AI 的 Claude 背调三步法，与原文标题"万能Prompt"高度相关，可作为 Codex 类 AI 实操参考。

### Prompt 模板①：公司画像

```
请帮我分析以下这家公司：[公司名称 / 官网URL]

我是一家[你的产品类目]的中国供应商，正在与他们洽谈合作。请从以下维度给我一个分析报告：
1. 公司核心业务和主要产品线
2. 目标客户群体和主要销售渠道
3. 公司近期的业务动向（扩张/收缩/转型？）
4. 他们在选择供应商时，最可能关注的3个核心诉求
5. 与他们沟通时，我应该避免踩的3个雷区（如：价格敏感、交期要求、认证要求等）
```

### Prompt 模板②：行业动态扫描

```
客户所在行业：[行业，如欧洲中型家居零售商]
客户所在国家/地区：[国家]
当前时间背景：[年份 + 季度，如2026年Q2]

请帮我分析：
1. 该行业当前面临的最大外部压力（政策/成本/需求变化）
2. 行业里最近有哪些大的事件或趋势（关税/环保法规/消费降级/AI冲击等）
3. 这些变化会怎样影响他们的采购决策？他们会更保守还是更激进？
4. 我作为供应商，现在切入的时机怎么样？有哪些切入点值得重点强调？
```

### Prompt 模板③：竞争对手推演

```
我正在和[客户国家]的[行业]客户谈合作，产品是[产品类目]。

请帮我分析：
1. 他们通常会同时接触哪些类型的供应商（中国工厂/贸易公司/本地代理/其他国家工厂）？
2. 中国供应商在这个品类上，相比其他竞争来源，最大的优势和劣势各是什么？
3. 如果客户已经有了一个稳定的中国供应商，我要替换他，最有效的切入角度是什么？
4. 请给我写一段英文开场白（4句以内），能在第一封邮件里就让客户感受到"这个供应商跟别人不一样"。
```
